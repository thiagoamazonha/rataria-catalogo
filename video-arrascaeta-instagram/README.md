# Vídeo Instagram — Arrascaeta (música inteira)

Projeto de vídeo para publicação no Instagram usando a música completa do Arrascaeta.

## Estrutura

- `mockups/` — mockups completos (1080x1920, formato Stories/Reels)
  - `mockup_arrascaeta.jpg` — estampa Arrascaeta (costas grande + frente peito)
  - `mockup_camisa10.jpg` — estampa Camisa 10 (frente + costas)
- `ampliacoes/` — imagens de ampliação (zoom) em alta resolução
  - `ampliacao_arrasca_frente.webp` / `ampliacao_arrasca_costas.webp` (1440x2560)
  - `ampliacao_camisa10_frente.webp` / `ampliacao_camisa10_costas.webp` (1125x2000)
- `musica/` — colocar aqui o arquivo da música (ainda não adicionado)

Os arquivos são cópias dos originais em `img/`; o catálogo continua usando os originais.
